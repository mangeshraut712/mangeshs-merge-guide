# Security

The installer copies local skill files; optional evidence helpers read GitHub data using your existing CLI access. Installation does not grant permission to send messages, publish code or change accounts. Keep real ledgers, tokens and private session data outside this repository.

## Report a concern

Do not put credentials, personal data or exploitable vulnerability details in public issues. GitHub private vulnerability reporting is not enabled for this repository as checked on 14 November 2026, and no dedicated private reporting address or response SLA is established here. You may open an issue asking the maintainer for a private contact route without including sensitive details. Wait for that route before sharing them.

Ordinary reproducible bugs without sensitive details belong in the issue templates. Include package/source version, runtime, operating system and a synthetic reproducer. See [CONTRIBUTING.md](CONTRIBUTING.md).

## Version scope

npm 0.1.1 is the current public release. Review source/release notes before assuming later `main` fixes are in that artifact. No guaranteed support window or security response time is promised. This policy does not replace an upstream project's own disclosure rules.
